# 三网可达性测速记录

> 用途：决定是否需要为 `gzalex2020.github.io` 前置 Cloudflare 或改用 EdgeOne Pages。
> 本文件只提供记录模板，**不在代码侧做任何假设**。

## 测试方法

在电脑 PowerShell 与一部移动卡手机上各跑一遍（每线路 10 次）：

```powershell
1..10 | % { curl.exe -o NUL -s -w "tcp=%{time_connect} tls=%{time_appconnect} ttfb=%{time_starttransfer} code=%{http_code}`n" https://gzalex2020.github.io/tongbuke/ }
```

## 判定规则

| 结果 | 动作 |
|---|---|
| 三网 10/10 且 ttfb < 600 ms | 维持现状，不再引入额外代理 |
| 移动 < 8/10 或 ttfb > 1.5 s | 可选 Cloudflare 橙云前置（SSL 选「完全（严格）」），与现有腾讯云 GA 二选一 |
| 家长规模破 1000 人、需要正式运营 | EdgeOne Pages；大陆可用区需 ICP 备案 |

## 观测备注

- 本项目的构建环境解析 `gzalex2020.github.io` 得到 `185.199.108~111.153`（GitHub Pages / Fastly 段），未观察到工单所述的 `106.55.101.131`。可能是本地 DNS/代理差异，也可能是腾讯云 GA 未生效，需以用户侧三网实测为准。
- 无论采用哪种 CDN，analytics 仍保持 `ENDPOINT = ''` 零外联；不要叠两层代理，否则客户端 IP 会失真。
